# Laufzeit von Filmen und Serien Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** TMDb-Laufzeiten in `movie-db` speichern, für Serien die Laufzeit der ersten Episode verwenden und in der deutschen Oberfläche anzeigen.

**Architecture:** Die Laufzeit wird als nullable Integer `laufzeit_minuten` in `movies` gespeichert. Der TMDb-Mapper liest bei Filmen `runtime` und bei Serien `episode_run_time[0]`; Collection-Import und Backfill verwenden dasselbe Detailmodell. API- und Frontend-Typen reichen das Feld bis zu MovieCard und Detailansicht durch.

**Tech Stack:** Express, TypeScript strict, better-sqlite3, Vitest, React 18, Vite, TMDb API.

## Global Constraints

- UI- und Fehlertexte bleiben Deutsch.
- Neue TypeScript-Codepfade verwenden kein `any` und keine Inline-Casts beim Zugriff.
- Bestandsdatenbank wird über `ensureColumn` migriert.
- Bestehende Ratings, Watch-Status, Notizen, Listen und Quellen bleiben unverändert.
- Tests zuerst; danach `npm test`, Server-Typecheck und Client-Build.
